# Queue

For the person running many agents at once, whose job is never to leave one waiting.

Agents are listed by who needs you first. The selected one's live terminal sits beside the list,
so answering an approval is typing into the real terminal, not opening anything.

It only claims what it saw: a time is shown when the change happened while the view was open,
and a remembered one only while the agent is still in that state.

It asks for nothing beyond showing your workspace: it cannot start, close or message agents.
